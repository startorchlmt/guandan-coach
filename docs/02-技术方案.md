## 1. 架构

```
React UI (pages/Home.tsx + components)
   │ 状态驱动
   ▼
对局状态机 (src/lib/guandan/game.ts)      —— 发牌/轮转/进贡/名次/升级/整局

   ├── ai.ts        出牌搜索与启发式决策（AI 与教练共用）
   ├── coach.ts     事前推荐/事中评估/事后复盘/摸底题
```

引擎全部纯 TS、零 DOM 依赖、种子随机（mulberry32）可复现；Node 24 直接跑测试。

## 2. 核心数据模型

- `Card = { id: number, suit: 0-3(♠♥♣♦), rank: number }`；rank：3–13=3..K，14=A，15=小王，16=大王。两副牌共 108 张，id 全局唯一（区分同点同花的两张牌）。
- 级牌 `level`（3–14 区间内的 rank 值，从 3 即"打 2"用 rank=2 表示……实现口径：levelRank ∈ {2..14}，2 用 rank 值 2 表示——注意这与牌面 rank 3–16 错开：牌面没有 rank 2 的牌除非级牌为 2 时 2 指牌面"2"。**统一口径：牌面 rank 集合为 3..14(A)、15/16 王；"2" 的牌面 rank 记为 15？** —— 见 §7 风险 T1，采用：rank 2..14 表示 2..A，15=小王 16=大王，级牌 level ∈ 2..14）。
- `Play = { type, cards, mainRank, length }`；type ∈ single/pair/triple/fullhouse/straight/pairseq/tripleseq/bomb/straightflush/jokerbomb。
- 比较键：炸弹优先级 bombRank = 天王炸>8>7>6>同花顺>5>4；级牌比较时把 level 映射到 14.5（介于 A 与王之间）。

## 3. 牌型识别（patterns.ts）

- `analyze(cards, level): Play | null`：先分离百搭（红桃 level），对无百搭直接按计数/连续判定；含 1–2 张百搭时枚举替补方案（每个百搭可替补为 2..A 任意点；同花顺还需同花色），取能构成的最强牌型。
- `beat(a, b, level): boolean`：a 能否压 b——炸弹 vs 非炸弹、炸序、同型同长比主点。
- 顺子窗口：自然序列 2..A 滑窗 5 连 + 特判 A2345 回绕；普通级牌按牌面点数参与窗口，序列比较用牌面值（不经 cmpRank 提升）。

## 4. AI（ai.ts）

- `enumerateLeads(hand, level)`：生成领出候选（单/对/三/三带二/顺子/连对/钢板/炸弹，贪心扫描，数量有上限）。
- `enumerateResponses(hand, level, toBeat)`：只生成同型更大者 + 所有炸弹。
- `choosePlay(state, seat)`：评分 = 出手后手牌评估增量（剩余手数、炸弹保留、大牌控制）+ 战术项（搭档已赢本轮且点数小→倾向 pass；对手剩 ≤5 张→倾向压；自己剩 1–2 张→优先出走）。强度定为中等偏稳（需求 R5）。

## 5. 教练（coach.ts）

- 事前：`recommend()` 复用 choosePlay 的评估，输出 top-3 候选与理由文案（规则化文案模板：留炸/清小/接风/逼炸等）。
- 事中：`evaluate(sel)`——analyze 失败→非法说明；合法但与 top1 评分差 > 阈值→劣着提示（轻量提示条）+一键改出；否则通过。评分差分档：小亏仅记入复盘（R2/R6）。
- 事后：回放日志逐回合比对玩家选择与 top1，生成失误/亮点/建议。
- 摸底：3 道静态题（牌型识别、大小判断、策略选择），答对 ±50 分/题。

## 6. 评级（rating.ts）

- `delta = 基础分(胜负+升级幅度) × 决策系数(0.6–1.4)`，掼力 clamp [0, 4000]；段位 9 级分段映射。

## 7. UI

- 牌桌：四家手牌区（玩家明牌，其余背面+计数）、出牌区、级牌/进贡状态条、教练面板（推荐/提示/理由）。
- 流程：摸底(首局) → 进贡弹窗 → 回合循环（点选牌→事中校验→确认）→ 局后复盘报告 → 战报海报（Canvas 绘制 → toDataURL 下载 PNG）。
- localStorage：掼力/段位/战绩/是否已摸底。

## 9. 风险

- T1：rank 编码与级牌提升容易出边界 bug → 统一编码 + 测试 26–55 全覆盖。
- T2：百搭枚举组合爆炸 → 百搭最多 2 张，枚举空间有限；同花顺枚举个位数。
- T3：自动对局死循环 → 步数上限熔断 + 测试断言收敛。
- T4：出牌枚举性能（27 张手牌） → 候选数设上限 + 贪心扫描，浏览器单步 <50ms 可接受。
