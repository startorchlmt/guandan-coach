# 掼蛋军师 · AI 掼蛋教练 —— 需求方案 v1.0

日期：2026-09-13 ｜ 状态：待评审

## 1. 产品定位

**一句话：一个会教人的掼蛋游戏——AI 在你每次出牌前给建议、出牌时纠错误、牌局后做复盘，并用「掼力值」给你定段位，目标是快速提升牌力。**

形态：纯前端本地 Web 应用，规则引擎 + 启发式 AI 驱动，离线可玩，零 API 成本。

## 2. 目标用户

掼蛋新手与进阶玩家；工会/企业赛事组织者的陪练工具。

## 3. 牌局规则（本实现采用的规则集，须与引擎严格一致）

- 4 人两副牌（108 张，含 4 王），玩家坐南家（0 号位），搭档为对家（2 号位），1/3 号位为对手。南+北一队，东+西一队。
- 每人 27 张。级牌从 2 打起；级牌大于 A、小于小王；**红桃级牌为「逢人配」百搭牌**（可替代除王以外任意牌）。
- 牌型：单张 / 对子 / 三同 / 三带二 / 顺子（恰好 5 张）/ 连对（恰好 3 对）/ 钢板（恰好 2 个三同）/ 炸弹（4–8 张同点）/ 同花顺（5 张同花顺子，属炸弹）/ 天王炸（四王）。
- 顺子规则：不含王；A 可高（10-J-Q-K-A）可低（A-2-3-4-5 回绕顺，打 2 时亦合法，2 在其中按自然低点参与）；**普通级牌按牌面点数参与顺子**（如打 5 时 ♠5 可进 3-4-5-6-7），序列比大小只看牌面值（级牌在序列中不提升）。
- 大小：同牌型同长度比主点；级牌 > A > K > … > 2（2 非级牌时自然序）；炸弹压一切非炸弹；炸弹序：四王(天王炸) > 8 张炸 > 7 张炸 > 6 张炸 > 同花顺 > 5 张炸 > 4 张炸；同张数炸比点数。
- 轮流出牌，首家领出任意合法牌型，后续须同型压过或 pass；三家连续 pass 后该轮结束，最后出牌者领出下一轮。
- 名次按出完顺序：头游/二游/三游/末游。
- 进贡：末游向头游进贡最大单牌（不含逢人配），头游还贡一张 ≤10 的牌；若为本方双下（对方一二游），则双贡双还；末游方持有两张大王可抗贡。
- 升级：本方一二游（双下）升 3 级，一三游升 2 级，一四游升 1 级；级牌序列 2→3→…→A。打 A 时：本方须头游且搭档非末游才算过 A 获胜，否则继续打 A；连续 3 次打 A 不过，退回 2。先过 A 的队伍赢得整局。

## 4. 功能需求

### 4.1 牌局（P0）
- 完整实现第 3 节规则；3 个 AI 陪打（搭档 1 个 + 对手 2 个）。
- AI 策略：合法出牌搜索 + 手牌评估（炸弹数、控制力、剩余手数、搭档信号），具备基本的"让搭档/压对手"意识。

### 4.2 教练系统（P0，产品核心）
- **事前指导**：轮到玩家时，给出推荐出牌方案（含理由，如"留炸""先清小牌""搭档在接风"），并可查看 2–3 个备选方案对比。
- **事中纠正**：玩家选定牌后、确认前进行校验——非法牌型说明原因；合法但明显劣于推荐方案时弹出纠正提示（说明亏在哪、推荐什么），玩家可采纳或坚持（坚持也允许，记入选牌日志）。
- **事后复盘**：每局结束生成复盘报告：胜负与升级结果、关键失误列表（偏离推荐且造成损失的回合）、亮点操作、三条针对性提升建议。

### 4.3 等级定位（P0）
- 掼力值：初始 1000，每局按胜负与升级幅度增减，并按「决策准确率」（采纳/符合推荐方案的比例）加权修正。
- 段位映射 9 级：入门 → 新手 → 铜牌 → 白银 → 黄金 → 铂金 → 钻石 → 大师 → 掼圣。
- 首局前提供 3 题「牌力摸底」（牌型识别/大小判断/策略选择），决定初始掼力偏移（±150）。

### 4.4 精彩时刻与分享（P0）
- 自动识别精彩时刻（出炸、天王炸、翻盘获胜、双下、连扳级数等），记录回放日志。
- 局后生成「精彩时刻战报」海报图（Canvas 绘制：战绩、掼力变化、段位、精彩瞬间描述、复盘金句），可下载 PNG。
- 明确说明：微信不允许网页直接分享到朋友圈，产物为保存图片后手动分享；DOM 录屏受浏览器限制，v1 采用「精彩回放动画 + 海报图」替代视频录屏。

### 4.5 残局模式（P1）
- 入口：首页可切换「完整对局 / 残局挑战」。
- 残局库：内置经典残局（如「大王锁喉」）+ 随机生成（南 3–5 张、其余 2–4 张）；每局残局经博弈树求解器（minimax + 记忆化）验证**只有唯一取胜首着**，目标为己方头游。
- 过程无事前/事中指导；AI 对方走启发式最强抵抗，搭档走求解器胜着。
- 结算后逐步复盘：我的每一手标注 ✅/❌，错着给出正解与理由，并附完整正确线路演示。
- 残局分与掼力值相互独立：破解 +100，未破 +15，单独持久化（localStorage `guandan-endgame-v1`）。

### 4.5 持久化（P1）
- localStorage 保存掼力值、段位、历史战绩。

### 4.6 非目标
- 不联网对战、不做账号、不接真实微信支付/分享 SDK、不申请任何知识产权（上次已结论：玩法不可专利；本产品的可保护资产为软著+商标，由用户自行办理）。

## 5. 质量要求

- 规则引擎为纯函数模块，种子随机可复现；任意状态下 AI 与教练给出的出牌必须合法。
- 自动对局模拟不得出现死循环：任何完整牌局在合理步数内收敛结束。
- 玩家任何操作路径（乱选牌、非法组合、pass、坚持错误出牌）均有正确反馈，不得卡死。
- 中文 UI，桌面优先，响应式。

## 6. 验收标准

1. 牌型识别覆盖全部 11 种牌型及逢人配参与的组合；大小比较符合第 3 节。
2. 引擎级自动对局模拟（多种子）全部正常收敛、名次/升级/进贡逻辑正确。
3. 教练推荐出牌 100% 合法且能压过上家（或明确建议 pass）；事中纠正对非法/劣势选择均有覆盖。
4. 掼力值有界、段位映射正确、摸底题影响初始值。
5. 100 条自动化测试全部通过；`npm run build` 成功。

## 7. 自评审记录（2026-09-13）

| # | 发现的问题 | 严重度 | 处置 |
|---|-----------|--------|------|
| R1 | 掼蛋规则存在地域变体（顺子是否含 A2345、钢板能否带对、双贡规则细节），不写死会导致实现摇摆 | 高 | 第 3 节已逐条写死为「本实现规则集」，UI 内提供规则说明页；变体支持列入 v2 |
| R2 | 「事中纠正」若每次都弹窗会严重打断出牌节奏，引起反感 | 高 | 分级：非法→阻止+说明；明显劣着→轻量提示条（非弹窗）+可一键改出推荐；小亏→仅记录进复盘，不打扰。补充进 4.2 |
| R3 | 「录屏发朋友圈」在纯网页技术上不可直接实现（无微信 JS-SDK 权限、DOM 无法直接录屏） | 中 | 已在 4.4 如实降级为「回放动画 + Canvas 海报图保存后手动分享」，并向用户明示 |
| R4 | 摸底题若影响初始掼力过大，会造成段位失真 | 低 | 偏移限定 ±150（约半个段位），并标注"仅供参考，实战校准更快" |
| R5 | AI 搭档若太强，玩家没有发挥空间，教练失去意义 | 中 | AI 强度设为「中等偏稳」：不犯错但也不神操作；精彩与失误空间留给玩家 |
| R6 | 掼力值若只按胜负调整，运气成分过大，无法反映"牌力提升" | 高 | 胜负增减 × 决策准确率系数（0.6–1.4），复盘页单独展示准确率曲线，二者解耦呈现 |

**评审结论：R1/R2/R6 为高严重度，均已在正文中修订或明确实现口径；R3 为能力边界，如实降级并向用户明示。需求方案修订为 v1.1，通过，进入技术方案。**
